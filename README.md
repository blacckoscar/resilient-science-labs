# Resilient Science Labs

A React marketing site for Resilient Science Labs — engineering intelligence for biological adaptation.

Built from the official brand system (deep forest `#123D32`, adaptive lime `#A8D85F`, mineral blue `#547E8D`) and the approved homepage, platform, report and hero designs.

## Local

```bash
npm install
npm run dev
```

## Stack

Vite, React, React Router. Static hosting on Vercel.
